# GenAI Usage Appendix

## Tools Used

- AI assistant for planning the architecture and implementation sequence
- AI assistant for refining API structure, documentation scaffolding, and testing scope
- AI assistant for drafting supporting written materials

## How AI Was Used

- Project planning and decomposition
- Reviewing model boundaries and API grouping
- Drafting documentation structure
- Generating candidate implementation approaches for ingestion, recommendation, and analytics
- Improving wording and structure for submission-facing materials

## Human Oversight

- Final implementation decisions were reviewed before being applied
- Code and documentation were checked locally
- Project-specific tradeoffs were chosen manually
- Unsupported or weak suggestions were discarded rather than accepted automatically
